## ✨ Key Features

*  **Personal Portfolio** – Showcases personal information, skills, projects, and achievements.
*  **Project Showcase** – Displays completed academic and technical projects.
*  **Skills Section** – Highlights programming languages, development tools, and technical skills.
*  **Resume Section** – Provides access to professional and academic information.
*  **Responsive Design** – Designed to provide a consistent experience across different screen sizes.
*  **Contact Section** – Allows visitors to connect through the available contact information.
*  **Jenkins CI/CD** – Includes a Jenkins pipeline for automating the project workflow.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/dhanashree340-cmyk/portfolio-project.git
cd portfolio-project
```

### 2. Open the Portfolio

Navigate to the portfolio directory:

```bash
cd portfolio
```

Open the main HTML file in your browser.

Alternatively, use **VS Code Live Server** to run the portfolio locally.

### 3. Run with Jenkins

The repository contains a `Jenkinsfile` that can be used to configure a Jenkins pipeline.

General workflow:

```text
GitHub Repository
       ↓
Jenkins Pipeline
       ↓
Build / Validation
       ↓
Deployment
```

### 4. Access the Website

After running the project locally, open the URL provided by your local development server in a browser.
